How to run a practice day

Back to the controller

Sign in with your code

The controller asks for one thing: the access code you were given. Type the letters and digits. You do not enter a name. KartBoard finds the matching controller and this device stays signed in.

An older numeric code still works in the same field. After a match, the page says Signed in as that controller. A code that does not match stays on the sign-in card.

Show me

The Show me button is at the top of the controller. Turn it on to learn the page. The layout stays the same, a banner and a green tint show that learning mode is on, and tapping any control opens a note instead of changing the day. Nothing is sent that would alter practice.

You can do this before you sign in. This device remembers the switch. Turn Show me off before you run the day.

A typical race day

  1. Before the first session, open Day setup. Set the venue, the practice label, the usual session length, and the class order. Save.
  2. Tap Start first session. The public board shows that class and the countdown.
  3. The session buttons sit in four rows of two. Pause holds the countdown. Continue starts it again from the time that was left, or after a break. Continue is the resume action.
  4. Advance by 1 minute makes the current class end one minute sooner. Add 1 minute gives it one minute more. The public board updates immediately. The clock does not go below zero, and neither button skips a class.
  5. Previous class goes back one. Next class starts the following class with a fresh countdown and clears a paddock notice. The large button under the clock still starts the first session of the day.
  6. Changeover is the gap between classes. Take a break is a longer stop. Continue returns to the same class. Next class moves on.
  7. To change what comes later, hold a class (or use its handle), drag the order, and tap Done. The class on track keeps its clock.
  8. Post a short paddock notice when people need a message that stays on the board.
  9. At the end, tap Finish day.

If someone else changed KartBoard

Every change includes the revision you last saw. If another controller saved first, yours is not applied. A banner says the board was refreshed. Read the new order, tap Refresh if you want to load it again, then repeat the change if you still need it.

Sign out

Sign out clears the sign-in on this device only and shows the access-code card again. The public board stays as it is. Other phones that signed in keep their own sign-in.
