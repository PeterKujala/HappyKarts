**PROPOSED** — discussed possibility  
**OPEN QUESTION** — unresolved

## 4. Add AI continuity instructions

Near the beginning of `PROJECT_CONTEXT.md`, include a section called:

`## Instructions for AI Assistants`

It should explain that:

1. This file is the persistent context/memory for the project.
2. An AI assistant should read this file before making substantial project changes.
3. It should inspect the actual current code rather than assuming this document is perfectly current.
4. Actual code is authoritative regarding current implementation.
5. Important product, architectural, requirements or implementation decisions made during future sessions should be incorporated back into `PROJECT_CONTEXT.md`.
6. Completed or materially changed work should be recorded in `CHANGELOG.md`.
7. Documentation should be updated rather than endlessly appended, so obsolete information does not accumulate.
8. Historical decisions that remain useful should be preserved, especially the reasoning behind them.
9. The assistant must not silently reinterpret IMPLEMENTED, DECIDED, PROPOSED or OPEN QUESTION items.
10. Before ending a substantial development session, the assistant should consider whether these files need updating.
